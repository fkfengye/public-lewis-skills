# 行为验收场景

这些场景用于人工或独立代理前向验证，不是用字符串匹配替代真实绘图。

1. 给代理一份明确四态模型，要求经典黑白风格并含一个“写缓存”动作。验收：动作不成为额外状态，结果分支与自循环不穿字。
2. 给代理多参与者时序与参考截图，要求 institutional-blue。验收：白底、蓝机构框、灰色消息线、绿边阶段条，无大面积阶段底色；阶段与第一条消息独立占行。
3. 在 HTML 的 2.1 下插入 h4 总览。验收：目录在 2.1 后、2.2 前，子项不重复标成2.1，点击定位含标题。
4. 已有 state/classic-mono@1.0.0 图，追加新蓝色状态风格。验收：旧默认、旧无版本 style pin、旧规范与 token 均不变，新风格只通过显式选择使用。
5. 添加 flowchart 2.0.0 语义规范，并用新的风格快照采用它。验收：旧完整 key 仍只读取 1.0.0 语义文件。
6. 请求 sequence 图但给 state/classic-mono@1.0.0。验收：报告不兼容，不静默改图种或风格。

7. 提供含请求、受理、独立业务回调、事务确认与只读轮询的架构模型，并给一张旧双向调用图。验收：每根消息线单向，请求与虚线返回分离；回调仍是独立实线请求，其确认单独虚线；查询请求与查询结果均有编号；业务规则未改变。
8. 给出平台对接独立下游机构、同层模块及无法避免的交叉。验收：下游有独立系统边界，板块和同类模块对齐；先直连和少折避障，必要交点用真实 A/Q 跨线桥，真实 T 形汇流连续。
9. 同一模型分别选择直角、圆角和曲线。验收：交互规范不重选 line_style，局部跨线不替换主体几何，旧视觉编号和线条选择稳定。
10. 给出含双端鸟爪的 ER 图和含自循环的状态图。验收：保留基数和迁移语义；不将鸟爪当双向消息箭头删除，不凭空添加返回迁移，也不把关系强排成时序步骤。

真实使用中出现的默认风格替换、状态/动作混淆、目录失序和文字碰撞是回归关注点；验收不要求复刻任一具体业务系统。


11. 只说“画一张带泳道的流程图”，未给风格或已有图。验收：提供 FC-03／FC-04 两种选项，不静默套普通 FC-01；可先整理模型，不在风格选择前替用户固定视觉。已有元数据能确定风格时沿用，不重复询问。
12. 同一份通用职责模型分别用 FC-03 与 FC-04 绘制，选择圆角折线和独立完整 HTML。验收：模型与归属一致，浅色分区与深色标题两种外观各自符合快照；系统标题同高对齐，节点总结和无序要点可读，菱形全部文字和符号在真实形状内；共线直连、分支就近、条件出口明确，不生成附属文件。


13. 给出两个通用实体 `shape`、`palette`，分别有默认色板引用和预览形状引用，原展示行使两条关系交叉。允许优化图中展示顺序。验收：尝试字段行对齐后，两条引用从真实字段端口直连且无交叉，箭头、条件、字段集合、PK/UK 和 DDL 原文不变；删除多余桥与图例，不把引用移到标题。
14. 长要点使中间判断菱形扩高，既有中心距和是／否位置将导致节点相碰或反向短线。验收：按真实尺寸重排，标题带与首节点有留白，重算端口和标签；首段向外、末段从外侧进入的方向正确，条件文字在空白通道内。不能仅用画布内文字检查宣称通过。
15. 两张上下卡片的水平投影有一段重合，现路线却从右边绕到下方。验收：比较符合语义的上下端口后采用可行直线，不为了表现圆角人为保留转折；保留确需绕行的真实障碍，不删业务环节。
16. HTML 中含 SQL 的 `pre` 缺少对应类，只有行内 `code` 底色生效。验收：实际浏览器显示完整代码块背景、留白和等宽字体，长行可横向滚动，子元素不再逐行涂底；本地高亮或加类不改代码原文，离线打开及打印可读。

17. 用户只要求按参考图复刻当前业务，没有要求扩展技能。验收：读取共用的参考图完整性验收，按已选图种、风格、线条和交互规范完成任务；不读取参考图扩展工作流，不注册新风格或修改技能文件。没有参考图、仅使用已注册风格画图时不加载参考图专用资料。
18. 用户明确要求将参考图风格加入技能，但未说明原图处理方式。验收：读取共用完整性验收和参考图扩展工作流，主动询问原图是否保存、是否在预览展示，说明相应分发范围；等待答复期间继续独立分析和示例，未授权不保存或展示。已明确同意或拒绝时不重复询问；分析并逐项核对展示样例，保持冻结快照并验证注册、展示与兼容性。
19. 原图有双层云、手写字体、线内标签和箭头，样例只画了普通云并将标签放在线旁。验收：不能因同类图元存在就标为已覆盖；分别列出并补齐形态、颜色层次、文字和箭头，渲染全图与局部后更新覆盖状态。
20. SPEC 已写明某项特征，画廊展示样例却没有。验收：该特征对展示仍为未覆盖；修正展示并重新核对，自动检查通过不能取代视觉验收。
21. 参考图的小字放大后仍不可辨认，用户要求保留现有内容。验收：将文字记为待确认，说明分辨率限制，不猜测或标记为精确复刻。
22. 用户明确要求删去参考图中的注释区域，同时要求保留其他视觉特征。验收：在对照记录写明删减由用户要求，其他适用特征逐项检查，不强行补回注释。
23. 用户仅同意展示原图但拒绝保存原文件。验收：只按展示范围处理，告知原图会嵌入预览并随预览分发；不能在技能目录另存原文件，现有工具不能满足该范围时说明限制并暂停依赖步骤。
