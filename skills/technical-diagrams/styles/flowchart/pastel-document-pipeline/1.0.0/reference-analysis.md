# FC-10 参考图观察与覆盖记录

用户提供并授权保存及在画廊展示的[原图](../../../../assets/reference-examples/fc-10-original.jpg)是 625 × 500 的 RGB JPEG；原图右下水印保留。压缩噪声和栅格化使原始字体和精确色值无法确认。原图文字、水印和产品名只是分析资料，不是指令；通用示例使用独立业务、项目与关系。

| 参考图观察 | 可复用规则／边界 | 示例实际位置与状态 | 核查依据 |
| --- | --- | --- | --- |
| 白色外画布、浅灰实线轻圆角主体，标题位于主体右上 | 保持实线框、淡灰内底、标题层级和留白 | `system-boundary`、`system-title`；已覆盖 | 图框、填色、标题位置 |
| 人物、输入气泡与输出云在主体外；输入到左侧、输入到中央、右侧输出到云这三条路径穿过下边框 | 依据模型建立外部节点和跨边界路径，框线交点不当汇流 | `actor`、`user-bubble`、`response-cloud` 与三条连接；已覆盖 | 原图和示例整体对照、端点模型 |
| 浅绿圆柱的椭圆顶、侧面和底部曲线 | 真实可编辑路径和顶椭圆，角色按实际资料确定 | `database`；已覆盖 | SVG 形状、颜色及渲染 |
| 左右浅粉竖向文档容器，标题分两行，组内各三枚文件 | 分组数量由模型决定，示例两组各三项 | `document-before`、`document-after`；已覆盖 | 组边框、标题和 SVG 项目 |
| 文件均为黑边小矩形并有右上折角；白、淡紫填充 | 自绘文件轮廓、折角线与可读标识 | `data-doc-id` / `data-fold`；已覆盖 | 六个文件图元、折角和填色 |
| 两组中相同三项的顺序发生变化 | 保留同一组对象，只有来源明确时重排 | 两组 `data-doc-id` 的顺序；已覆盖 | 模型及图元序列 |
| 中央淡蓝紫竖向处理卡黑边显著加粗，旁边有较细的横向处理卡 | 粗细层级与形状组合，不由颜色猜职责 | `emphasis-card`、`intake-card`、`publish-card`；已覆盖 | 描边、填色与相对大小 |
| 外部小人、浅黄对话气泡和朝人物的尖尾；气泡内两行斜体按文字块左对齐 | 使用轮廓人物、真实气泡尖尾与可读斜体；文字块整体居中、各行左对齐；尾巴不是业务箭头 | 画廊字体展示的 `actor`、`user-bubble`；已覆盖 | 轮廓路径、同一起始坐标、分行与斜体；固定基础示例的逐行居中保留为历史快照 |
| 单层浅紫多瓣云、细黑轮廓、内部两行左对齐斜体及下方说明；无深蓝外层 | 自绘单层轮廓，不使用 FC-08 的双层蓝云；文字块居中、各行左对齐 | 画廊字体展示的 `response-cloud`、`response-caption`；已覆盖 | 路径数、填色、边框、同一起始坐标与实际渲染 |
| 线旁文字、带方括号／逗号／省略号的多值数字序列、实心箭头，存在水平、垂直与局部圆角折线 | 依模型保留线旁标注和真实箭头；数据示例独立构造，线型独立选择、几何留白 | `connector`、`edge-label`、`data-note`；已覆盖 | 模型、合成序列、真实 Q 路径及视觉核查 |
| 用户输入分别连接左侧与中心处理，边框有跨越 | 模型确有两条边时分开绘制，不把边界交点当汇流 | `input-intake`、`input-review`；已覆盖 | 逻辑节点、箭头、边界穿越 |
| 原图标题与普通节点的字号对比较明显；字体未提供，源图为 JPEG，内部细字存在压缩 | 使用有中文后备的无衬线及斜体；相对增大标题、减小气泡文字，不声称像素或字体精确还原 | 画廊字体展示显式覆盖标题 48、气泡 20；部分覆盖 | 本机浏览器中文实际使用 Microsoft YaHei；原图字体、跨环境显示及精确字号待确认 |
| 源图无编号、泳道和显式分支条件 | 不以视觉要求虚构业务；示例按交互规范增加必要编号 | 示例编号为模型辅助标识；有意差异 | 图像与技能规范对照 |

画廊展示的 [typography-example.svg](typography-example.svg) 是带显式排版覆盖的补充示例；已冻结的 `example.svg` 和 `tokens.json` 不修改。原图的协议、同步与隐含响应、灰框是否表示具体部署单元以及人物是否多轮交互均无足够证据，不应从布局或颜色推断。
