# FC-06 全局深蓝标题纵向泳道：参考图分析

## 画布和层次

- 原图尺寸 4587×4361，接近方形略宽，图像为调色板模式且无透明通道。外侧浅灰留边，内层为大面积白底；顶部贯穿全部泳道的深蓝总标题栏，标题白色居中加粗。其下是一排白底部门表头，粗体黑字，表头下边界及竖直泳道分隔均为细浅灰线。
- 原图为四个竖直职责泳道；前三列近似等宽，最右列更宽以放并列节点与回路。泳道数量和宽度是具体实例，不作为固定规则。主线总体向下推进，中间通过左右跨泳道连接和返回路径回流，不是每一横行代表一个阶段。
- 不使用阴影、渐变、图标、图例、阶段栏或节点编号；留白较多，节点按局部行列对齐。单独的全局标题与白色部门表头是两级结构，不应误画成每条泳道各有深色标题带。

## 图元、颜色和文字

- 深蓝标题栏与判断菱形近似 #354865，流程线同色；浅蓝灰动作节点近似 #D2DCE7，起止胶囊为中蓝近似 #4272C0。白色正文背景、浅灰边界和深色文字以实际显示为准，上述取样为近似值。
- 开始和结束为蓝色胶囊白字；处理活动是浅蓝灰圆角矩形、黑字；判断节点为深蓝菱形白字，形状与颜色均有区分。各同类节点基本同尺寸，部分节点多行文字居中。
- 原图有一个长文字处理框的底部文字被裁切；复用时应根据内容扩展容器、合理换行，不能把这一缺陷作为风格。中文为清晰的无衬线字体；总标题、表头、节点文字各有层级。

## 路径、节点归属和不确定项

- 路径是深蓝实线，终点为实心三角箭头；有垂直、水平直线和直角折线，存在跨泳道直连、从外侧绕行的长回路和向左返回。应先按模型与端口选择直连；转角形态由用户选择的线条规范决定，不因原图采用直角而锁死其他选择。
- 节点归属由其所在竖列表示，不能因跨列箭头或相邻推定所有者。泳道分隔线是边界而非消息；流程线之间有视觉交叉，原图未给出连接点或跨线图例，不能仅凭交叉推断汇流。
- 多个菱形的出口没有标注“是／否”等条件，某些菱形文字更像动作名称而非明确问题，条件及其完整业务含义不能从视觉推断；复刻应忠实标记不明，新示例则按独立业务模型明确分支。
- 原图存在跨越多列的回流和反馈节点，但不意味着所有流程都要外绕或拥有相同节点数。颜色、起止形状及箭头方向是视觉规则，不应自动赋予未标出的业务状态。

## 展示样例对照

通用示例需可见：全局深蓝标题栏、白底粗体部门表头及竖线分隔、不同宽度泳道、蓝色起止胶囊、浅蓝灰圆角处理框、深蓝白字菱形、水平与垂直直连、必要直角折返、跨泳道消息和真实反馈回路；节点、条件和拓扑以独立场景建模，并按实际内容扩容避免裁字。示例不必复用原图中的部门、动作、节点数量或来源图像素材。
