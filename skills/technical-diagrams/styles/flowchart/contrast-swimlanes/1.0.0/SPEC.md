## 视觉规范

白色画布与白色泳道正文，深色标题带集中表达系统归属。调用方参考深蓝 #284E73、核心服务参考深青 #176B75、协作方参考蓝灰 #53637E；按输入实际职责选择色组，不凭颜色推断部署或业务状态。泳道细边框 #CBD9E4，标题带等高 104，顶部圆角 14、下缘平直，左右内边距 28。

主标题白字、30、600 字重；副标题 22，分别用 #DCE8F4 / #D8EFEB / #E4EAF4。标题分“系统／模块名＋职责说明”两级，同层顶边与标题带高度对齐；窄泳道先缩短非关键信息或换行并等高扩容，不挤压标题。标题文字与深色底对比至少 4.5:1。节点归属标签沿用所在泳道标题色，长图依靠归属标签辅助定位，不反复插入标题带割裂连线。

动作节点仍为浅蓝 #EDF3FA、判断米黄 #FFF8E8、文字深蓝 #174C7B、连线蓝灰 #7C909E。颜色集中在标题带，避免正文大面积着色；不用渐变、阴影、装饰图标或无业务含义的徽章。

## 语义、归属与节点读法

绑定 `types/flowchart/1.0.0.md` 与 `references/common/1.0.0.md`，并同时遵守解析出的交互规范与独立线条规范。泳道是同一流程图中的真实职责分区，不是新图种、运行阶段或状态。先为节点记录 owner，再按输入依据分组；不得把“成功、失败”当作系统名，也不因为调用就把下游归入上游。

每个节点先用一句话总结“谁做什么”，再以无序列表逐点说明来源中存在的输入、校验、动作、结果或约束。归属短标签置于节点上方内容区，长图中也能辨认执行方。列表正文左对齐；长要点使用悬挂缩进，续行对齐正文首字。不要把一串细节挤成一段，也不为填满卡片补造规则。

## 布局与连线

泳道默认纵向、主流程自上而下。先联合确定节点网格、文字尺寸与上／下／左／右端口，再选择通道。水平直连按连接端口中心线对齐；不要仅对齐框顶，再用弯折补偿高度差。主链下一步紧接当前判断；各场景节点放在不同条件出口附近，不让主链为侧向终止路径空出整块高度。可水平或垂直直连且无障碍时必须直连，必要绕行才增加转折。

先尝试换端口或调整节点位置，再接受更长外绕。标题和装饰分隔线不是整幅不可穿越障碍，不能成为绕画布的理由。每条有向线只在终点有一个箭头；确有数据返回时另画独立虚线，不能给每个处理框虚构确认。

本风格适用于直角折线、圆角折线及直连曲线；最终几何由独立 line_style 决定。example.svg 显式选择 rounded-orthogonal@1.0.0，必要转折用真实 Q 路径、参考半径 18，短段收缩。这只是示例选择，不改变注册表线条默认值，也不把固定视觉编号与圆角绑定。

## 文字、尺寸与验收

正文参考 22、行为标题 24、归属标签 18、线标 20，字体 Microsoft YaHei / Noto Sans CJK SC / Segoe UI / sans-serif。尺寸以真实字体度量决定；增加行数应扩容节点与间距，不缩小字号或省略关键字。矩形检查实际文字边界；菱形必须逐行检查文字及项目符号的角点位于真实菱形内，不能只检查外接矩形。

逐边比较当前路径与直连、其他合理端口及节点重排的弯折数和距离；同时检查语义、障碍和标签空间。真实汇流连续，无关交叉使用局部圆弧桥，不用遮罩掩盖穿字。渲染后核看全图、长文字、判断分支与跨泳道连接；检查节点归属、方向、条件、无重叠和无穿字。
