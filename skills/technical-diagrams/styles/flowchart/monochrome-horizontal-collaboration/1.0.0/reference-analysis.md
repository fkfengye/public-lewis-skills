# FC-05 参考图视觉分析与特征清单

用户允许分析视觉特征，不允许保存或展示原图；此文仅记录可复用的版式和抽象关系，不保存原图的业务名称、数值、素材或元数据。对应示例使用独立的虚构模型。

## 画布、布局与图元

- 源文件 2016×696，RGB 不透明白底，宽高比约 2.90。宽横幅画布，主图占据大部分宽度；无总标题、图例、色块、图片、装饰、阴影及泳道。
- 六个白色圆角矩形，黑色细实线边框，圆角较小；节点内黑色文字居中。水平主链为四个高矮相近、宽度不完全相同的矩形，中部上、下各有一个附属矩形；左、中重点名称更粗，其他名称较轻，底部节点文字两行。节点是不同参与方而非流程控制符号；不能因常规流程图惯例增加未出现的起止、判断、泳道或步骤。
- 全图近黑与白色为主，白底 #FFFFFF，文字、轮廓、连接线接近 #000000；无彩色区分、渐变或填充强调。抗锯齿与压缩在黑白交界产生灰色，不应当成独立色彩类别。中文无衬线，字号有主次；节点文字在框内居中，关系标签靠近对应线段，长文字可换行。

## 连线结构与含义

- 主链相邻节点通过水平黑色实线和填充黑色箭头连接，其中一对参与方还画有各自独立的平行虚线反向线；两条线使用不同端口和各自箭头，不合并成双向箭头。顶部与中部用向上的虚线连接；中部向底部为垂直实线；顶部另有一条沿外侧延伸、拐向右侧下行的虚线，末端带箭头。
- 合计可见七条有向线：三条水平前向实线、一条水平反向虚线、一条上行虚线、一条下行实线和一条上方右侧绕行虚线。图中文字标识大部分线的作用，外侧绕行线没有独立标签；未标注不等于可猜测内容。
- 普通线较细，顶部外侧绕行虚线明显更粗、虚线间隔更大；箭头为黑色实心三角形。标签置于对应线的上方、下方或近侧。节点、标签、线段和箭头之间有留白；图中没有菱形、条件分支文字或颜色图例。
- 不把虚线一律解释成返回、异步、资金路径或其他业务；只能使用图中明确的标签及来源语义。外侧虚线是否代表额外业务关联或特定阶段，未标明的部分保持待确认。线条的颜色、粗细、虚实及空间位置不能单独证明步骤先后、部署或责任归属。

## 视觉规则与独立展示覆盖

| 观察 | 独立示例覆盖 |
| --- | --- |
| 白底、黑框、少量圆角和黑色居中节点 | 有；节点宽度不同，含重点粗体与两行节点 |
| 线性主链与上下分支 | 有；采用五个主链节点及上、下节点的独立模型 |
| 黑色实线和黑色箭头，反向独立虚线 | 有；每条有向线分别建模，真实方向及样式由模型给出 |
| 上行虚线、下行实线、粗的上侧外绕虚线 | 有；外侧线不强加标签 |
| 相邻线标签错位、必要长线和留白 | 有；含一行和两行文字，不用遮罩掩盖穿线 |

节点数量、名称、边和业务取决于用户来源；示例不是对原图的业务复刻，不把任何单一领域固化到样式。
