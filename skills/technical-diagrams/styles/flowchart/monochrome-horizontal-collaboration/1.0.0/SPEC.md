# 黑白横向协作流程 · FC-05 · 1.0.0

适合描述角色、系统或机构之间有向协作的流程图。白色宽画布、白色小圆角矩形、黑色细实线边框和居中文字；重点节点可加粗，长名称扩容或换行。同层节点水平排列、节点宽度依文字确定，上下节点按真实关系布置；没有标题、颜色、判断或泳道时不凭视觉偏好添加。

以黑色细实线或虚线及黑色实心箭头表达来源明确的有向关系，线型与含义由来源、模型或图例说明；不将虚线自动等同返回或异步。两个相反方向的真实关系用独立路径、端口、箭头与标签，不能画成无说明的双向箭头。可使用更粗的外侧虚线表示来源明确的独立路径；没有标签的关系保留未标注，不补造数据或含义。

共线无障碍优先直线，只有绕开节点或按所选线条规范确有需要才转弯。直角、圆角折线或直连曲线仍由独立线条选项决定；外侧路径的箭头端点、虚线样式和语义不得随外观变更。文字与线条留真实空间，源/目标、实际方向、线型和标签须与模型一致，不用白色遮罩掩盖穿线。

本风格可将参与方直接表示为节点；在来源中它们是实体时，不把它们扩写为虚构动作、强制加开始结束或菱形。实际动作节点仍按已知内容总结。配色、字号与间距见 token；参考图可复用特征见 FC-05 视觉分析。
