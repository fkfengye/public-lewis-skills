# 手绘运行边界流程 · FC-08 · 1.0.0

以白色宽画布和充足留白组织编号流程，主要处理位于带手写感标题、深色细虚线和圆角的大边界内；与该边界有实际区别的参与者、资源区域及工作单元放在边界外。按来源确定归属，边界不自动代表部署或组织关系。文字采用圆润自然的手写字体：拉丁字符优先 Virgil，中文优先 Xiaolai，并提供可读后备；这些字体有各自的 SIL OFL 1.1 许可，具体来源与再分发要求见 [字体许可](FONT-LICENSE.md)。离线交付时将实际使用的字形和许可内嵌；若所需字体或字形不可用，应告知回退造成的外观差异。标题、节点、步骤和说明有清晰层级；按实际字体度量调整尺寸，避免把参考图小字照搬到成图。边框、卡片与椭圆可使用轻微不规则但连续的自绘轮廓和圆线帽营造手绘感；变化幅度须克制，连接端点仍落在真实边界，不让抖动损伤可读性或伪造交点。

按模型选用少量柔和的绿、黄、紫、橙、粉、蓝色，结合带文字的圆角卡片、判断菱形、椭圆资源池、人物设备和云形图标；颜色与形状不自行赋予业务语义。云形以错层的深蓝外轮廓色块和偏浅蓝内轮廓色块形成手绘双层边缘，不加黑色描边；文字居中、连线只接云的实际外边界。资源集合、池内实例或工作单元可用轻微错位的重复外轮廓表示，叠片为集合装饰，不自动生成多个连接或部署单元；可在彩色工作容器内安排小卡网格。数量、方向及嵌套关系都由本次模型确定。

以相互独立的有向路径表达步骤：步骤编号和主标签置于连接线的路径线上，依据真实字体测量留出间隙，让连线在文字前后真正断开；较小的补充说明可放在线旁。逻辑上仍是一条边，保留完整逻辑路径与两端端口，仅终点保留箭头；无空间时调整节点或路径，不用白色遮罩伪造断线。条件、基数和图种专用标签遵守相应语义与线旁约束。允许有明确含义的循环弧线、回退路径和单独的异常说明区，说明区不替代真实异常分支。请求与确认按实际语义分线，返回用独立虚线；装饰弧线不得冒充业务边。真实边界、跨边界路径、分支出口和箭头留出空间；不使用双头线或遮罩掩盖线穿字。三种线条样式独立选择，先按语义和端口比较直连，再依现有规范处理必要弯折与跨线。

展示示例为独立虚构场景；原图内容与不确定性见 [视觉分析](reference-analysis.md)，不可当作新图业务模板。
