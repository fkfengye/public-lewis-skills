# 手绘设计讨论流程 · FC-07 · 1.0.0

绑定流程图语义与公共规范。白色画布、手写感标题、虚线圆角说明框，浅蓝节点采用圆形、圆角矩形或矩形；按流程模型表达动作、判断、起止、条件与归属。节点、标签和排版按来源与实际语义确定，不由颜色或位置推断步骤。

粉色便签以手写感文字与轻微错位边框呈现；便签与注释箭头单独建模，不自动构成业务节点或流程边。可在节点边缘贴附自绘技术图标，不自动增加节点或连接。深色细线采用开放 V 型箭头；直连优先，必要绕行按独立线条样式选择。线旁标签保留实际空隙，不遮盖穿字。字体使用可读后备；根据真实文字尺寸扩容，内容不得裁切。参见 [视觉分析](reference-analysis.md)。
