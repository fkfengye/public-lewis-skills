# 细线组件交互流程 · FC-09 · 1.0.0

适合同时展示处理步骤、系统组件及外围交互的流程。白底宽画布，主体与外部组件按真实模型排布；无需凭空添加开始、结束或判断。实体、分组、处理动作和关系均由实际来源确定。采用本风格不意味着所画对象必须是监控系统或任何固定产品。

## 视觉与构图

主体采用浅米橙矩形、细灰短虚线边界和居中加粗标题；主体内部可并列白色细边直角卡片。相邻灰色支撑区域和深灰白字卡片只在模型确有对应区域时使用，邻接不自动表示部署归属。外部可组合米白细边节点、浅蓝标题／浅蓝正文列表卡、横向或纵向分格卡，以及小幅错位的重复轮廓；列表可含省略项，叠片可为两层白色、三层白色或两层米色等组合。叠片仅在来源明确表示多个实例或已标注图例时作为复数符号，不固定业务数量。

样例参考色值、字号与线宽见独立 [tokens.json](tokens.json)。标题、组件名和说明使用近黑无衬线字体，辅助列表使用灰色；中文按环境选择可读后备字体。依据真实字体度量扩容和换行，不假设参考图的字体名称、字号或被截断的文字。

## 连接与语义

连接使用细灰实线和终点实心三角箭头，常用正交线路，标签在线旁并留出真实空隙。共线且无障碍时优先直连，三种独立线条样式仍由用户或已有元数据选择。多个端口、平行通道、共享路径和扇出只在真实模型支持时绘制；逐条记录端点及语义，真实共享干线与非连接交叉必须能区分，不能把相交、近邻、粗竖线或叠片自动解释为总线、汇流、部署或依赖。按现有交互规范区分真实请求、返回及独立通知，不补造确认或协议。

多路扇出可用明确的分发节点或有清楚模型的共享线段；右侧分格外可使用由各格短线接入的竖向共享干线，真实 T 型分支保持连续，确有转折时可采用局部圆角。每项仅在来源或模型明确时使用，每个实际目标均应有正确方向。线旁标签支持单行或多行，均需避让线路和主体边框。避免穿过无关卡片和文字，不能用白色遮罩伪造避让。路径比较、必要圆弧跨线桥及逻辑编号遵守通用线条和交互规范；颜色或样式不单独定义业务语义。
