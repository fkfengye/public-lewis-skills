# 手绘粉彩数据流 · DF-01 · 1.0.0

使用白色宽画布与充足留白，自然摆放节点。过程可用浅蓝圆形，外部实体及存储可用不同粉彩直角矩形；形状和颜色只是一种视觉约定，角色以模型或图例为准，不声称符合某个标准。组件下方可采用同色系更深的右下硬边偏移色影，细深色轮廓，不使用模糊阴影。

节点文字居中、可换行，手写字体搭配可读中文后备字体；边标签使用清晰深色字体。依据真实文字调整尺寸与端口，标签处预留真实线段间隙，不能用白色遮罩伪装避让。相反方向的数据流使用两条独立线和各自标签、实心箭头；方向未明的连线无箭头并注明待确认。几何与线条选项独立，优先共线直连。

节点数量、颜色归属、关系和位置由用户来源决定；不默认套用参考业务、凭证、拓扑或未明确的调用关系。具体来源细节见 DF-01 原图分析。
