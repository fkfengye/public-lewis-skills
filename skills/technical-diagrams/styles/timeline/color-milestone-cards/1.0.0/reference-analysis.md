## 画布、结构与排版

- 图片为 1850 × 654，约 2.83:1；白底横向宽画布。没有总标题、图例、阴影、渐变、照片或图标。六列时间、节点、下方卡片横向对齐，卡片近等宽等高，节点间距近似一致。
- 日期置于对应节点正上方并居中；灰蓝细水平轴穿过节点中心，最右端有绿色细线与绿色右向实心箭头。六个节点由左到右排列，但参考日期跨越的时间间隔不同，间距不代表精确比例。
- 每个节点是**浅色外圈／光晕、白色内环、实色圆心**组合；其主色依次为棕、橙、蓝、青、紫和绿。每个节点下方有一根与节点同色的竖向虚线，连接到对应卡片上边缘；虚线不是业务调用，也没有箭头。
- 卡片为白底、同色细描边、大圆角矩形；上边框与标题带之间保留一小段白色空间，内部标题带为无圆角的实色色块。标题为白色粗体居中，正文为灰蓝色居中。
- 正文通常分两块：上部两行、下部三行，中间留出较大空白。文本、色块、节点和时间在各自列内水平居中。列数及文字行数是原图的具体安排，不强制用于全部时间线。
