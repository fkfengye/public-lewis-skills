# 彩色里程碑卡片 · TL-01 · 1.0.0

白色宽画布沿水平方向展示时间轴和事件，可按内容调整画布比例、事件数量及换行。时间文字放在对应节点上方；细灰蓝轴线穿过节点中心，末端可用方向箭头；轴只表示时间方向，不自动定义因果或调用。

节点可采用浅色外晕、白色内环与同色实心圆，并按事件选择棕、橙、蓝、青、紫、绿等颜色。每个事件下方以同色竖向虚线连接卡片；该线是无箭头的说明归属，不是请求、响应或事件依赖。颜色按模型和阅读需要选择，不固定六个事件或把色彩当成状态。

卡片采用白底、同色细轮廓、大圆角和实色直角标题带；标题带上方保留白色空隙，标题白色粗体居中，正文灰蓝居中，可分段及多行。以真实文字宽高决定卡片和画布尺寸，必要时调整排版、拆图或滚动，不能遗漏内容或将长字挤入固定卡片。

选择顺序轴或比例轴并按时间线语义规范明确说明：不等时间间隔若采用等距顺序布局，不得声称按比例；近似日期、并列事件、区间及相对时间保留来源精度。线条样式独立选择不会改变时间先后、精度或因果；轴与引导线的几何、终点和意义由时间语义及模型决定。
