# 多层时期事件时间轴 · TL-02 · 1.0.0

使用白色横向画布和居中标题，将时间轴置于靠下位置；可用深蓝紫粗实心带和末端三角箭头表示时间方向，年份沿轴标注，关键年份加粗。左侧可用浅蓝右尖标签和旋转文字标明不同观察角度；标签数量、名称和高度由资料决定。

同一轴可分层展示：上部用细水平括号和端点竖线表示时期，中部用浅蓝、青绿等粗单向箭头表示较大区间、用黄色粗箭头表示子区间；事件可通过不同高度的细竖线、轴上圆点和顶端菱形标记，辅以黑色文字；相关区间可使用括号标注。轴下可用带双端标记的细区间线和文字表示另一观察角度。上述箭头和括号仅表示时间范围或方向，不是消息或因果。

保持事件、时期和不同角度区间的来源及边界；不从颜色、排列、交叉或顺序推断因果、角色或部门。比例轴使用统一时间映射定位所有事件与区间端点，并标注时间尺度；非比例顺序轴说明间距不代表时长。开放区间、近似日期和不确定值按时间线语义规范保留原样。

长标签通过错层、换行、扩容或拆图消除重叠，所有事件引线、括号与所属标签明确对应；多数线可直接水平或垂直连接，不为展示风格制造折线。线条选项不改变轴尺度、时间精度或区间语义。原图内容和未核实项见 TL-02 原图分析。
