# 蓝紫虚线分区架构 · AR-10 · 1.0.0

使用白色宽画布，以浅色虚线圆角分区组织职责。可在一侧设置纵向支撑区，主体采用上方横向接入区、下方两个并列区；真实分区数、大小及系统归属由用户资料决定，不从空间邻近推断内部归属。

分区使用浅绿、浅蓝、蓝灰及淡紫等配色，标题在左上方用对应强调色加粗。内部模块采用白底、彩色实线圆角边框，标题居中加粗，下一行用较小的灰蓝说明；可按职责使用竖排、横排、两列或跨列宽卡。无需固定模块数量；长文字换行或扩容，避免挤压分区和连线路径。

交互可使用青蓝实线，并按实际模型使用红色强调方向或紫色虚线表示来源明确的独立连接；线色和虚实不得无依据地定义协议、状态或同步异步。标签靠近对应路径并保证可读，线和箭头不穿文字或节点；分区虚线不是连接。

线条几何与风格独立：共线且无障碍优先直连，必要绕行遵循用户选择的直角、圆角或曲线。圆角示例应记录真实线条选择；无关线路交叉需调整路径或用真实圆弧跨线桥消歧，交点不是自动汇流。箭头只放在实际目标端，响应／回调按实际消息语义及交互规范独立绘制。
