# AR-12 原图视觉分析与特征清单

原图经用户明确授权保存和展示。以下内容按截图记录，不证明图中能力已实现；原图 CDP 业务名、节点和数据类型不自动用于其他系统。

## 原图内容与归属

- 总标题为“CDP产品功能架构”。第一层“决策应用”包含 360°客户画像、个性化推荐、智能营销三张图文卡片。
- 第二层“分析应用”包含漏斗分析、分布分析、用户留存分析、用户路径分析、归因分析、Dashboard 六张图文卡片。
- 第三层“数据处理”包含三张白色面板：数据清洗为三列三行，依次是数据去重、格式转换、数据合并、数据拆分、异常值处理、数据分组、空值/null值处理、数据计算、数据过滤；数据整合为一列三行，依次是 ID Mapping、多用户ID整合、多渠道ID整合；数据安全和隐私为两列三行，依次是数据脱敏、合规审查、数据加密、数据备份和恢复、数据授权、敏感操作日志。
- 第四层“数据采集”包含一方数据和三方数据两张面板。一方数据四列两行：自有线上电商/app、PC/移动门户网站、营销活动后台、财务系统、线下门店管理、电商管理系统、优惠券管理、线下收银系统…；三方数据两列两行：合作媒体、广告流量平台、运营商、第三方电商平台…。
- 从下层向上有四枚宽箭头，箭身分别标注“消费数据”“用户数据”“行为数据”“流量数据”，均换成两行白字。它们表达数据类型向上流动，但图中没有给出具体来源小格与处理小格的一一对应关系。

## 画布、分层与组合

- 图像尺寸 2182 × 1697，宽高比约 1.29:1；白色背景，顶部留白、深蓝粗体总标题水平居中。没有图例、页脚、阴影或虚线边界。
- 四条浅蓝横向底板自上而下堆叠并留白分隔，底板为小圆角、无明显外边线；第一层较浅、第二层略高，第三层和第四层容纳更密集的网格。每层左缘以浅蓝灰粗体竖排层名标识，层名逐字纵向排列，不是竖向旋转整行英文。
- 第一层有三张近等高的宽白色小圆角卡；每卡采用左侧彩色插画、右侧深蓝加粗标题，图文横向居中。第二层六张较窄白卡横排，仍是左图标右文字，图标的色彩、线条和大小各有区别。图片部分是不同插画而非统一轮廓图标；通用示例应自绘不同的可编辑图标，不复制来源插画或品牌。
- 第三层三张不同宽度的白色圆角面板并列：左宽、中窄、右中宽；面板标题顶部居中。细小条目为白底、蓝色细实线圆角边框和居中文字；依次采用 3×3、1×3、2×3 组合。
- 第四层两张白色面板并列，左宽右窄；面板标题居中，左侧为 4×2 条目、右侧为 2×2 条目。面板、层底板与条目是三个嵌套层级，不能把每个细条目都当成独立部署单元。

| --- | --- |

| 四层底板 | #D1E8FF |

以上为原图像素近似值，插画还有青、黄、绿、橙、紫、红等强调色。中文无衬线，总标题最大且加粗；面板标题、图文卡标题较大加粗；条目文字略小、常规字重。顶部层和第二层标题靠近图标、水平排列；竖排层名和内部标题分别有独立位置。

四枚蓝紫粗箭头跨越最下层和第三层之间的边界，箭头朝上，宽三角形箭头与较窄矩形箭身相连，双行白色标签放在箭身中；箭头可呈深浅不同的蓝紫。其他相邻层之间未绘制箭头、实线、虚线或具体节点连线；不能仅凭上下位置推断它们存在调用、数据接口或执行顺序，也不能由箭头标签推断数据协议和具体业务处理。
