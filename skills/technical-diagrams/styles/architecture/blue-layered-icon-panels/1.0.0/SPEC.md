# 浅蓝图标分层面板 · AR-12 · 1.0.0

以白色画布和居中主标题组织纵向堆叠的浅蓝色小圆角底板；可在每层左侧以逐字竖排文字标注层名。每层的数量、大小、名称、顺序及归属来自实际模型，竖排仅适合可读的短层名；长名称可调整布局或改用横排。

可在上层并排放白底小圆角图文卡，以可编辑的彩色插图在左、深蓝粗体标题在右。插图以自有或获授权素材表达实际内容，可采用不同的造型与强调色；不复制参考图品牌、图标或业务。其他层可用不同宽度的白色圆角面板组织矩阵，面板标题居中，内部白底细蓝边圆角条目按内容排布；条目不是自动产生的独立系统或部署单元。

来源明确存在层间数据关系时，可用向上的粗蓝紫箭头，宽三角箭头和较窄箭身组合，白色短标签可分两行置于箭身内。箭头的数量、方向、标签与真实端点由模型决定；无连接的层和模块不凭位置补出调用或数据流。普通节点连线仍按实际关系及独立线条规范选择；向上不自动等于返回消息。

基于 tokens 设置配色、字号和组件间距，真实文字和图标决定卡片大小；不依固定卡数、矩阵列数或像素位置挤压内容。原图中的画布、插图、矩阵及连接不确定项见 AR-12 原图分析，独立展示样例不能当作用户业务事实。
