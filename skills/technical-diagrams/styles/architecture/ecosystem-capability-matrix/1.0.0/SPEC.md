# 蓝粉生态能力矩阵 · architecture/ecosystem-capability-matrix@1.0.0 · AR-07

本风格绑定架构语义与公共规范 `1.0.0`；配色和基础尺寸以本目录 `tokens.json` 为准。线条几何由独立线条规范选择，请求、返回、箭头、编号和系统边界遵守独立交互规范。用户提供的业务模型始终优先。

## 画布与层级

以白色宽画布分隔上、中、下层：上层用浅蓝紫色圆角容器组织外部参与方或生态能力；中层用宽幅浅粉容器承载主体能力；下层可用浅粉区域展示支撑网络、基础设施或其他真实归属。每层数量、位置与包含关系由实际任务决定；上层、侧栏和下层不因视觉距离被自动视作平台内部。

上层可将多个等高分组横向排列，组内白色圆角卡片展示子项；中层可在色块内以一张洋红重点卡搭配多张浅色描边卡，或使用根据内容确定行列数的矩阵；卡片可再包裹分栏信息条。底层可用圆角容器和一组白色胶囊表现并列支撑模块。仅在模型有明确归属时使用包含关系；主体标题、分组标题、卡片标题、正文与补充数字分级排版。

## 组件与配色

外部组以浅蓝紫背景及蓝色标题区分，中层和下层以浅粉背景、洋红边框及标题形成第二视觉层次。重点卡可用洋红实底与白字，其他卡采用白底／浅粉内容条，标题与信息列保持清晰对齐。白色圆角小卡、细分隔线、轻量圆形图标和大圆角容器可按内容选用；指标不应凭空编造。颜色和图标仅辅助阅读，不自动表示系统类型、状态、资金或消息含义。

深色正文与浅底、白字与深洋红底均应达到易读对比。标题文字、指标和普通说明保持明显层级；真实文字与字体度量决定容器尺寸。无需固定原图的品牌、厂商名称、图标、业务指标、模块数量或拓扑。

## 连接和图例

关系的方向、含义和端点来自实际业务模型；无障碍共线优先直连，需要绕行时才按独立线条样式转折。蓝色或粉色渐变可作为可选的方向视觉强调，但颜色不能取代文字、图例、线型和箭头；原图的深色虚线未说明语义，不得推断为返回。

每条有向交互只在终点画箭头；请求、独立消息与响应分别建模，按独立交互规范画实线或虚线。跨越非关联线时按规范区分交叉与实际汇合，跨分区保留清晰通道。不能用一条双向线表示两种消息，不能将布局中的上下或颜色自动解释为调用先后。

## 示例与验收

`example.svg` 是独立构造的社区知识服务示例，使用不同节点与关系演示蓝色生态组、粉色能力矩阵和支撑区；其名称、指标、关系和具体数量不是默认业务。用户明确授权的原图由风格目录另行提供，原图品牌或业务不因此成为通用模板。

核对主体分区与实际归属、每一层的标题和内容、卡片对齐与嵌套、颜色对比、各方向箭头和真实标签；预览全图和密集局部，检查文字溢出、节点碰撞及线穿字。自动渲染检查未覆盖的端点方向、节点碰撞和语义须另行人工核验。
