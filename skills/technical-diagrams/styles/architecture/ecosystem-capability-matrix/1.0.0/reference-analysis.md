## 整体构图与分层

原图尺寸为 1766 × 1324，横向画布约 4:3，白底、无外框。内容由上方生态参与区、中间平台能力区、下方支撑网络区构成，通过垂直留白和向下箭头分隔。视觉阅读先横看上层，再看中层卡片矩阵，最后看底部网络；这只是图中的摆放，不自动定义执行顺序。

上层五列横排：左右两列为窄版参与方，中心三列为等宽能力分组。两侧窄卡与中间区域之间留有空白、水平箭头及单字标签；中间三列各在下方放接入说明与向下箭头。左右卡位于不同边界，应依据实际归属分别建模，不能因为对称就归成同一内部系统。

中层为贯穿画面的浅粉大圆角区域：左上有品牌，中央有横向标题；内容区左侧是一张跨两行的洋红重点卡，右侧是 3 列 × 2 行的六张能力卡，列宽、行高、间距及基线一致。底层为左窄、中宽、右窄三个区域，中间容器内有标题与一排五枚白色胶囊，左右之间用水平虚线箭头连接。

## 上层参与方和分组

两侧窄版大卡背景为浅蓝紫色，顶部蓝色粗标题；内部各有三张白色圆角横向小卡，左侧灰蓝圆形图标、右侧深色文字。中间三组同样使用浅蓝紫大圆角容器，顶部蓝色标题；每组先放一张跨列白色说明卡，下面有两列两行白色子项。三组主体尺寸和间距一致，圆角较大，底边带有很轻的柔和阴影。具体厂商名和图标来自原图，不构成通用组件库。

上下游方向用淡蓝到亮蓝渐变的粗水平箭头提示；接入提示位于三组下方，配浅蓝渐变向下箭头。箭头的具体业务含义依原文标签和上下文解释，不能从颜色单独推导协议、请求、响应或资金方向。

## 中层平台能力矩阵

大容器采用浅粉色底、大圆角；左上为白底上的洋红品牌字样，标题居中。左侧重点卡为洋红实底，含白色线性圆形图标、白色标题及白底内卡；内卡中分两行展示数字与说明，由细横线分隔。重点卡纵跨右侧两行，显示主次关系，但不天然表示部署或数据所有权。

右侧六张卡为白色／近白色底、洋红细边、大圆角：标题靠左且用洋红粗体，右上是洋红圆形图标；卡片下方嵌入淡粉横向信息区，通常通过细竖线分成左右两栏，指标、单位及说明按不同字重区分。有的卡片左栏显示加粗数字，有的两栏均为短句；这些内容按各自业务决定，不能凭空补充数量或指标。容器、卡片、信息条、文字四层嵌套对齐，不用图标位置代替语义。

## 底层支撑网络与连线

底层左右为浅粉色矩形大圆角区域、洋红边框与居中洋红标题；中间是更宽的浅粉色圆角容器，标题同样居中，下面排五枚白底圆角胶囊。左侧向中央、中央向右侧各有一条深色虚线、空心箭头，方向由箭头决定；图中未单列虚线语义图例，不能推断为响应或确认。中层靠左、靠右位置各有一条粉色渐变向下箭头，连接下层区域的方式应按实际业务模型定义。

原图中的粗箭头以渐变色、箭头形状和留白突出方向；虚线颜色和形态有别于渐变箭头。新图仍须依现有交互规范区分请求、独立消息与返回，明确箭头真实端点，避免穿过卡片文字；只有实际需要绕行时才增加折线。色彩、渐变和线条几何是独立视觉选择，不能覆盖用户指定的直角／圆角／曲线选项。

## 验收重点

按真实系统边界划分参与者、平台、支撑区；核对横向对齐、留白、卡片包裹关系和层间箭头端点。核查深浅文字对比、指标与说明的分栏、圆角和描边一致性，并在缩略图与大图中分别查看文字、图标、标签、路径及节点间距。没有证据的线条语义、数据、品牌和拓扑不应带入其他业务；使用原图作为参考时明确标识其为原始样例。
