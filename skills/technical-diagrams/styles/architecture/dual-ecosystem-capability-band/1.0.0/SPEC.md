# 双侧生态与能力矩阵 · AR-15 · 1.0.0

采用白色宽画布，顶部可并排外部节点、上下渠道及中间的浅桃虚线组合框；组合框可含横向标题和多项子卡。两侧可放蓝灰背景、蓝色虚线边框的图标组，并以浅桃色虚线条标明分组。中央重点节点可采用白底粗蓝框、居中大标题和自绘图案；角色与归属由用户资料确定，不从位置对称推断。

下部可采用浅绿跨列底板，横向排列不同宽度的浅桃矩形能力组，顶部叠放淡蓝标题带；内部按内容使用虚线细项、并列与跨列卡。更下方可设置亮绿横条和居中标题；这些仅是组合和视觉层次，不自动成为系统、数据流或部署单元。下方可配置自绘参与者图标及标签，数量和类型根据模型选择。

同图可使用蓝色细实线、黑色实线或虚线、蓝色粗点线、开放箭头以及必要的球形中继图案；分别在模型或图例中说明真实关系，虚线边框、标题带和插画不能误当成消息线。未明确线色、虚实线和标志含义时不猜返回、协议、资金、实时性或机构边界。图标只作视觉说明，品牌素材仅在明确授权且适用时使用；示例使用非品牌图标。

直连优先，非共线时按独立线条选择调整；仅在来源要求直接扇出时可记录直线斜向覆盖。标注、箭头和连接必须避让组件和文字，检查真实端口和未连接交叉；必要时拆图。图形、标题、业务和语义由用户资料决定。原图多级组合和未确定事项见 AR-15 原图分析。
