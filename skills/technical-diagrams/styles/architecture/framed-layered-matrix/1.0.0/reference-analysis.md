## 画布和整体版式

- 整体为透明背景的近方形纵向架构总览。原始 PNG 的空白像素为 RGBA (0,0,0,0)，其 RGB 值不代表黑底；在白底上预览呈白色。顶部高饱和中蓝色横向实心标题带，居中大号加粗白字；左右两条贯穿主体的浅蓝竖栏，以及最下方浅蓝色横栏形成三面包围；中间是依次堆叠、层高不等的六个横向主体层。层与层、主体与侧栏之间通过明显的透明留白间隔分开；背景颜色随承载页面变化，展示示例使用白色背景；不把间隔误作连接线或阴影。
- 按图由上至下为用户层、应用层、应用服务层、基础服务层、数据层、基础设施层；它们是版面分层，顺序本身并不证明调用方向、部署或数据流。最底部横带“标准规范体系”，左侧竖带“安全管控体系”，右侧竖带“运营保障体系”，分别作为贯穿或支撑整体的标题标示；单字竖排居中，不是旋转整段文字。用户层、应用服务层、数据层与基础设施层左端有黑色粗体横排层名；基础服务层左端是逐字竖排层名。
- 各层浅灰白底，应用层三块淡紫蓝分区并排，宽度不等；基础服务层灰底，其内部上下两块浅色子区与右侧独立浅蓝灰窄栏之间由透明留白竖沟分隔。外框均为直角，无阴影、图标、图例或圆角卡片。

1. 用户层五个横向白色矩形：养殖场、屠宰场、官方兽医、协检员、各级动监所。
2. 应用层三组，顶部粗体标题居中：皖动监小程序 3×3（工作台、现场检疫、预警信息；扫码收证、回收台账、检疫申报；终端绑车、车辆状态、基础信息）；动物卫生监督服务平台 2×3（首页、现场检疫；检疫出证、便捷出证；出栏统计、回收登记）；动物卫生监督管理平台 2×3（检疫受理、官方兽医管理；机构管理、统计分析；检疫证查询、预警信息）。子组件为透明或同色底、细灰实线矩形，文字居中，较长名称换行。
3. 应用服务层七个横向白色矩形：养殖场备案、检疫申报、检疫受理、现场检疫、检疫出证、机构管理、用户管理。第一项两行。
4. 基础服务层：左侧“核心服务（CSP）”与“支撑服务（CSP）”上下分组。核心服务为产品中心、订单中心、用户中心、车辆中心；资产中心、合同中心、支付结算中心、发票中心；右侧“数据集成中心”为跨两行的高矩形。支撑服务是两行五列：文件服务、工作流服务、任务调度服务、短信服务、实时推送；电子支付、电子发票、电子合同、动态表单、统一编码。最右独立窄栏自上而下排列服务网关、服务发现、配置中心、服务鉴权、服务监控；其归属及是否与所有组件发生交互，原图没有连线说明。
5. 数据层四个横向排列的白底、浅灰边圆柱：检疫DB、starRocks、业务缓存DB、……。省略号表达未列明的其他数据项，并非一个具体数据库。

## 配色、字体、边界与连线

像素取样的主要近似色：画布及层间空白为透明（RGBA (0,0,0,0)，不是不透明黑色）；标题带 #5A99D8；左右与底部保障带 #BBDEFB；层底 #F5F5F5；应用分区 #DCE1F4；基础服务背景与节点浅边 #E0E0E0；右窄栏 #DEEAF6；节点白 #FFFFFF；文字 #323232；应用内边框约 #9E9E9E。显示和压缩可能影响边缘色。

中文无衬线；标题带白字最大最粗，层名和分组标题为较粗黑字，普通节点深灰、字号较小，普遍居中。左右栏大字逐字竖排，底带横排居中；应用层标题大于节点。基础服务标题分两行，英文缩写原样记为 CSP，两组使用同一缩写不推断其含义。

来源没有箭头、节点连接线、虚线、端口或图例；可见线条是矩形边框、圆柱外轮廓及分隔边界。位置、颜色、层序和透明留白分隔不表示请求方向、依赖、消息或数据流；不得补造关系。如用户另行提供关系，才按独立线条及交互规范绘制。
