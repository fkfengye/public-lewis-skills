## 外观与布局

宽幅画布使用浅青色外层系统边界，内部使用浅蓝、浅青、浅绿的矩形子分区；边界可用细实线，内部功能卡片可用细点线。上部可以并排放置职责相关的子系统，下部可用横向区域展示任务资料或共享能力；按真实归属安排，分区数量与位置不固定。

以清晰的矩形层级、同层对齐和紧凑网格呈现较多模块；外部系统保持独立边界。优先横排文字并根据真实字体扩容；密度不能以压缩字号、竖排长词、节点重叠或连线穿字为代价。内容过多时拆分系统总览与局部详图。

颜色和基础尺寸以本目录 `tokens.json` 为准；`example.svg` 是布局参考。任何模块、分组或数据关系只能来自当前任务资料，不能从示例推断。

## 交互与验收

请求／独立消息与返回分别使用单向实线／虚线，方向、标签和编号以模型为准。展示图例，不能只靠颜色推断语义；默认及转折样式由独立线条选择决定，不为了展示风格制造绕行。优先调整节点与端口，避免交叉；真正的汇流保持连续，必要跨线使用现有交互规范的真实弧桥。
