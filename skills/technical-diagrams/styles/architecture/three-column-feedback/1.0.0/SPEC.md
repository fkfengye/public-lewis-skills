# 三栏分区与反馈闭环 · AR-09 · 1.0.0

使用横向宽画布组织输入分组、核心处理和输出分组；左右可使用浅色底和同色虚线矩形边界，中间使用浅中性底、强调色实线及大圆角边界。区域的数量、位置和归属由实际模型决定；标题居中，留足区间连线空间，不将并排误作系统调用。

输入区可用两列配对：左侧圆角名称框，右侧较宽的直角说明框；各行按蓝、青、紫、橙、绿等浅色组合区分，并用文字表达类别。中间可用同宽浅蓝圆角卡片和浅红异常卡片；按实际模型决定它们是否连接或互斥，不因纵向排列添加处理顺序。输出区可用同宽圆角卡片及真实方向的纵向箭头，边框深浅辅助层次，不单独定义状态。

区域间共线时用浅蓝直箭头；输出内部可用绿色箭头。来源明确存在跨区域反馈时，可用橙色平滑曲线与就近文字从实际来源指向目标；反馈曲线是显式局部覆盖，其他连接仍遵循用户选择的直角、圆角或曲线规范。对请求、响应、回调的虚实线及语义以交互规范和实际资料为准，不将分区虚线当连接或仅凭颜色猜关系。无反馈关系时不得额外添加闭环。

保留底部回路及注释的空间，避免穿过文字、节点和无关边界；每条有向连接只在真实终点绘制箭头。长文字换行或扩容，标题、卡片与注释清晰对齐。颜色、字号和几何值见本风格 tokens；原图观察和不确定项见 AR-09 原图分析。
