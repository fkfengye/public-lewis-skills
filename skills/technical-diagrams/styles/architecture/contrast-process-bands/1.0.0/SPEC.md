# 暖底深绿分区 · architecture/contrast-process-bands@1.0.0 · AR-04

本风格绑定架构语义规范与公共规范 `1.0.0`。同时遵守解析结果中的独立线条规范和交互规范；颜色不单独定义业务语义。

## 外观与布局

暖白背景、深色标题和图例；以深绿大圆角区域突出一个重要职责分组，其他分组使用暖米色或浅青色，边框细而清晰。组标题靠边排列，同类节点按内容和网格对齐。必要时可使用中性灰色窄栏表示独立的存储或支撑组件；侧栏不是强制元素，也不代表独立部署。

内部节点以白色或深绿灰色圆角卡片为主，深色区域使用高对比浅色文字；判断可使用菱形，存储可使用圆柱或有明确标签的卡片。标题、节点、图例、文字与连线分别留出足够空间；长文字换行或扩容，不能缩小到不可读。

颜色和基础尺寸以本目录 `tokens.json` 为准，示例为布局参考。分组数量、节点位置和图例由实际业务与画布决定，不要求固定分层或侧栏。

## 连接与语义

实线、虚线、箭头和编号依照独立交互规范及实际任务解释；示例以图例标明连接含义。色彩仅辅助区分，黑白条件下仍须通过文字、线型与方向识别。

连接跨越深浅背景时按所在背景切换为高对比色；同一关系在背景边界保持连续，只有真实目标端绘制箭头。

优先直连与最少必要转折；直角折线、圆角折线或直连曲线由用户选择，不由视觉风格重设。无关线路跨越使用交互规范的真实跨线桥；真实汇流保持连续。不得按示例补造系统、请求、存储或关系。

## 示例与验收

`example.svg` 为独立设计的内容检索服务示例，业务名称、拓扑和数据均与参考材料无关，仅演示暖底、深绿分区、浅色辅助区、侧栏与连接图例。图种语义、归属和业务关系必须以本次用户来源为准。

验收全图与密集区域：检查标题与分组、节点边界、文字对比和溢出、箭头方向、标签与线路、真实连接和图例一致；结合模型检查节点碰撞及端口方向，自动渲染检查不能替代视觉与语义复核。示例及预览不得包含参考材料中的业务内容、品牌、原图、外链或隐藏信息。
