## 尺寸调整

基础正文字号 22、说明 20；缩放是 viewBox 到展示尺寸的等比映射。标签行数增加时扩容节点与行距，不把字号越缩越小。画布尺寸、泳道数、节点位置按业务模型调整，保持本风格的间距比例和线型。
