# 浅色横向分层矩阵 · AR-11 · 1.0.0

以白色画布组织纵向堆叠的浅色横向色带；色带用直角矩形和细实线，可依层级使用浅蓝、浅青、淡紫、浅灰底色。层数、次序和真实归属由模型决定。可将部分层标题放在左侧垂直居中，内容排列在右侧；其他层标题放在区域左上方，内容排在标题下方，不强制统一标题位置。

色带内可依内容排列同宽圆角卡、含细格和通栏的大圆角容器、两行细格矩阵及不同宽度的圆角卡。外层色带、模块容器和子项细格分别为直角／圆角／直角边框；卡片白底或同层浅底、细蓝／青／紫／灰边，正文黑色居中。长文字按实际度量换行或扩容，小格列宽可不同。

来源明确存在层级方向时，可在相邻色带的空隙使用浅蓝粗实心直箭头；其语义应由具体来源说明，不因上下位置擅自解释为调用、部署或请求。节点级关系仅在模型提供时绘制，不从容器或箭头推断子节点连接。线条几何与风格独立，端点共线优先直连，必要时遵循用户选择的直角、圆角或曲线；图中边框不是连线。

字号、颜色和尺寸以本风格 tokens 为起点；按实际文本及模块数量安排画布、层高和卡片宽度。参考原图的完整视觉层次及未说明的箭头含义见 AR-11 原图分析；通用示例不规定金融业务或引用源图中的品牌。
