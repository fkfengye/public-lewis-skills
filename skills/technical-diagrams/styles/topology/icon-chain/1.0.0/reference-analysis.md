# TP-01 原图视觉分析与覆盖清单

原图为用户提供并明确要求纳入的 PNG，仅作为风格参考与目录原始样例；图片的金融机构、货币、汇率和具体连接不成为拓扑图的默认业务。实际样例不得因配色或箭头猜测业务。

## 原图观察

- **画布与底纹**：1662 × 604，约 2.75:1 的横向画幅；无总标题、无图例或外框。背景白色与 `#F6F6F6` 近白细斜纹，节点之间及上下都留白。
- **整体层次**：从左到右排列银行、支付机构备付金、外汇合作银行、商户银行卡四个图标节点，近似同高同基线。节点上方为人民币、人民币、人民币→港币、港币等辅助文字，下方是较大的节点名称，部分名称分两行。上方另有两处橙红色汇率文字，并非同一总标题。
- **组件和图形**：节点无卡片边界。第一个与第三个是带货币符号的银行轮廓，第二个为屋形机构轮廓，第四个为实心遮阳棚加商铺轮廓；前几种图标以粗圆端线条为主，末一个同时有实心填充。图标大小相近但非完全一致。
- **颜色和文字**：高频色近似 `#FF3000` 橙红图标及顶部强调、`#A6A6A6` 灰色箭头、`#3D3D3D` 深灰文字；白色背景有细灰纹。中文无衬线、常规字重；节点名称大于上方说明，均居中；色值为像素近似而非来源设计令牌。
- **连线和方向**：三段粗灰色实心水平箭头，矩形箭身、三角箭头，连接相邻节点并指向右侧；箭头与图标间有留白。上方「人民币→港币」中的箭头是文字符号，不是一根拓扑边。原图无连线图例、编号、虚线、曲线、分支或跨线。
- **含义边界**：左右两处汇率标注的精确适用区间没有括号或明确端点；不得推断结算算法、协议、交易状态或资金含义。原图仅有四节点三方向边，不能从其单一示例限制拓扑图必须是链状。
