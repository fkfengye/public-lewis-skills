# TP-01 橙红图标链路 1.0.0

适用于节点较少、需要突出对象及其连接的拓扑。采用横向宽画布，白色或近白细斜纹底色，保留充足留白；按内容选择布局，节点多或有分支时可调整行列、画布或拆图，不丢关系。

以橙红色一致风格的矢量图标表现节点，轮廓与实心组合由实际对象决定，不加无意义的卡片背景。主链节点的图标中心尽量对齐，图标上方居中放辅助信息，下方放较大的深灰名称；长名称按内容换行或扩容。可在顶部放一处或多处橙红色说明，准确表达来源中的作用范围，不自动视为总标题或业务区间。

原图节点间采用浅灰色粗箭身和实心三角箭头，箭头与相邻图标保持间距。线条颜色、粗细、箭头和图例对应实际关系；有向、无向、不同连接类型由模型决定。三种独立线条几何均可选择：端点共线无障碍时直接连接；确需转折时分别使用直角、圆角或平滑曲线。箭头样式不决定连接语义或强制折线。

色彩、文字及几何以本风格 `tokens.json` 为准。节点数量、业务、图标类型、辅助标注、分组及路径不可照搬参考案例；明确区分展示样例、参考原图和实际业务。原图细节见 `reference-analysis.md`。
