# 分层图标集群拓扑 · TP-02

绑定拓扑语义和通用规范 1.0.0。白色底，纵向组织终端、入口组、主系统面板与底部资源，侧边可放独立能力栏。面板为白色矩形并以深灰细线描边，内部集群以浅红短虚线分组；青蓝、青绿、橙色图元与标签区分视觉类别。节点可重复排列成多列副本，图标应使用自有通用矢量，不复用来源品牌。颜色、分组、相邻与上下位置不推断连接、部署、协议或业务含义。

仅绘制模型中明确的有向、无向或多向连接；交互规范适用于实际消息而非普通关系。路径优先直连，转折依所选线条样式和真实障碍处理。扇出、集群成员、独立侧栏及资源区域均按来源建模；原图存在透明像素，应使用白底观察。详细观察见 [TP-02 视觉分析](reference-analysis.md)。
