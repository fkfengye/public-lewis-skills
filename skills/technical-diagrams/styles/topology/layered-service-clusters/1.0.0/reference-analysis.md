# TP-02 分层图标与集群拓扑：参考图分析

## 画布、透明性和布局

- 原始 PNG 为 1586×1512、RGBA，透明度范围 0–255，角点 alpha 为 0；呈现出的黑色外部区域是透明像素在深色背景上的显示结果，并非可直接推定的黑色画布。授权原图保留原始透明度，在白底查看；通用示例使用不透明白底。
- 画面大致从上至下组织：两个不同终端图标，汇入上方短横向的双实例入口容器；其下为宽大的白色主系统板块；左侧独立竖向窄板块、底部独立宽横板块与主板块相邻。右侧协调集群位于主板块内部。外围留白承担分隔，不是部署边界或数据连线。
- 主板块中上部为三个并排图标的入口组，中下部为三列服务分组、每组多副本；右边是纵向协调节点组。原图各副本、终端和分组的数量是本例，不规定通用拓扑数量。原图没有总标题或图例，侧栏和底栏用文字标识类别。

## 图元、颜色、层级与组合

- 白色实底矩形作为主板块、入口块、侧栏、底栏，轮廓为深灰细线；原图主面板取样约为 #1F1F1F，入口框约为 #2E363C，抗锯齿与透明度会使像素有所变化。通用样式采用近似的 #30363A；入口框圆角轻微。内部若干群组用浅红色短虚线描边的长矩形，表示视觉分组；虚线边框不是消息，不因包含或相邻推断额外部署或调用。
- 入口实例是蓝色圆角轮廓内的节点连接图标；主板块上方为青绿色椭圆外框与三角网络形图元；服务实例为橙色几何立方体形图标，按列排列；右侧为黑色轮廓组合图元；侧栏和底层资源为青绿色、蓝色的圆角图标加文字。图标只是视觉识别，新的通用示例须独立绘制，不复制商业标识。
- 背景透明、面板白色，文字与关系线深灰或黑色；节点类别颜色含蓝青、青绿、橙色，分组边界浅红。配色只用于视觉区分，不自动代表健康度、系统边界或调用语义。节点标签多位于图标下方，左侧类别名位于图标组左侧；部分侧栏标签两行。
- 原文件含多处倾斜水印，属于来源图片内容而非可复用视觉样式；仅原图入口展示原文件，不把水印和品牌素材复制进通用示例。

## 连接和语义边界

- 终端与入口用两条斜向深灰实线箭头汇入；入口与主板块之间有竖直线。入口组向下以斜线和竖线扇出指向不同服务列。图中既有单向实心箭头，也有双端箭头，以及右侧协调节点间的细线、空心箭头；个别区域线型、连接端点和图标具体归属并不充分明确，应逐条标记观察与待确认。
- 水平两端箭头只说明原图画出了双向端点，不能自动拆成两条特定协议消息；若实际来源明确为请求与响应，则按照交互规范分离，不凭样式编造请求或返回。线段、交点及箭头覆盖图标的地方必须核对真实端点；没有证据的交叉不是连接。
- 主板块入口与服务、服务组之间以及服务组与协调区之间有标注的线；协调组内也画有连线。侧栏和底部资源板块没有清晰完整的独立业务箭头，不能仅凭位置、类别名称或常识补充服务与资源之间的连接。
- 原图出现的产品名、协议名、技术栈和各分组身份是示例内容，不是 TP-02 的默认职责、技术选型、链路或因果关系。原图中的水印和品牌图标仅作为来源素材，不迁移到独立示例。

## 通用示例验收

可见覆盖：白底、两种终端图标及斜向汇入、双节点入口组、浅红虚线分组、横排入口图标及扇出、多列多副本服务集群、右侧纵向协调组、左侧窄竖向能力栏、底部横向资源栏；示例中有单向和无向或双向关系的区分并明确图例或说明。节点与组的归属、连接方向和端点由独立模型给出，资源区不能凭位置自动连接。按需调整图例与标注，不把原图的缺失或遮挡当作模板缺陷，也不虚构其业务含义。

风格卡片使用独立的[完整特征展示图](feature-atlas.svg)：入口采用圆角方形节点图标、网关采用椭圆图标；三列各三个通用副本，两组相邻集群各有上下两组独立请求与回应，协调组同时展示去向与回向及空心箭头，侧栏为蓝绿分类，另在主体左侧标识分发层和服务层。示例中的三副本与重复连线用于展示原图密度，不规定新图必须采用相同数量或业务连接。固定 profile 的原示例保留，不重绑或覆盖。
