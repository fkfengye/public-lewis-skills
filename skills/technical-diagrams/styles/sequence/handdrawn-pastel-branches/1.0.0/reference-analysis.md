## 来源语义与不确定项

原图从左至右展示客户、在线商店、库存、支付和配送；消息围绕购物及结算，含成功与失败两个互斥分支。成功分支中 “Delivery scheduled” 的虚线从配送一侧延至客户生命线并穿过商店激活条，究竟代表直接通知、返回还是简写无法仅凭图像确认；失败通知为虚线，也不能据此推断是否为独立通知或前一请求的响应。原图未编号，部分箭头形式也没有语义图例。新图以独立模型确定角色、方向及线型，不默认这些不确定含义。

色值为近似采样：奶白 `#FFFEF8`、黄 `#FCED9C`、绿 `#B7F1BC`、粉 `#F8C3D7`、青 `#E2F7F6`、青色标签 `#A3E8F1`、紫 `#D5C5FE`、蓝色轻影 `#B4DBFE`。原图字体未提供，Virgil 只是视觉接近的选择；中文及其他不可用字形要使用可读后备并说明差异。
