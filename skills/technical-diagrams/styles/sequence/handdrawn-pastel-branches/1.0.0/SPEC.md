# 手绘粉彩分支时序 · SQ-05 · 1.0.0

绑定 `types/sequence/1.1.0.md`、公共规范及独立交互规范。白色画布上方以圆润手写感标题、淡紫双笔下划线及与实际主题相符的自绘小图标组合；浅灰倾斜批注与细曲箭头可指向主图，但仅作为注记，不是消息，也不假定成品具有未实现的交互功能。参考图字号较小，按实际字体测量后调整尺寸和留白。

时序主体放在奶白底、近黑细虚线圆角面板内，右侧和底边可用浅蓝色细偏移描边形成不模糊的轻影。按模型排列参与者和纵向浅灰虚线生命线：人形角色可用淡绿圆头和深色细线身体；其他参与者使用等宽浅黄直角矩形与深色细边，长名称换行或扩容。只在实际执行期间画粉色细矩形激活条，依真实消息和模型确定起止，不以色彩、邻接或数量推断职责。

普通消息保持水平，单向请求使用实线；模型中确有返回或确认时另画反向虚线；独立通知和回调仍是实线请求。消息有独立逻辑编号，标签居中嵌入实际线段间隙，两行及长文字按照真实字体边界扩高、扩宽；逻辑消息、源与目标端口不因视觉间隙分裂，箭头只在终点。不使用白色遮罩遮盖线条。标题与参与者使用近似手写体，消息与条件使用细等宽体；英文可使用 Virgil，中文可使用合法且可离线使用的手写后备，缺字或缺字体时告知差异。字体和许可需按实际交付方式处理。

互斥分支用浅青背景的 `alt` 组合片段、深边浅青标签及细点线轮廓展示；每个分支的方括号条件、分隔线和各消息占独立空间，生命线可贯穿片段。`alt` 底色仅表示组合片段范围，不表示机构或阶段归属。参与者数量、分支条件及消息方向由用户模型决定；原图中的业务、图标及未经证实的返回语义不成为默认内容。

三种独立线条选项均保持普通时序消息水平，仅影响自调用和确需绕行的局部几何。详细特征与原图歧义见 [参考分析](reference-analysis.md)；颜色和尺寸见 `tokens.json`。
