# 蓝框机构时序 · sequence/institutional-blue@1.0.0

本快照绑定 `types/sequence/1.0.0.md` 与 `references/common/1.0.0.md`。只读取本目录 tokens.json；不继承其他风格默认值。

## 外观与排版

白底，统一浅蓝参与者矩形，机构仅蓝色外框，生命线与调用均灰色。阶段、关键说明使用白底绿边条，不用蓝绿紫大面积背景。alt/else/opt 用细灰虚线框；自调用用小侧回路。消息编号为小灰圆点，底部重复参与者。

颜色与基础尺寸以 [tokens.json](tokens.json) 为准，[example.svg](example.svg) 为布局锚点。示例业务只演示结构，不是需要复制到用户任务的系统、状态或协议契约。

## 尺寸调整

基础正文字号 22、说明 20；缩放是 viewBox 到展示尺寸的等比映射。标签行数增加时扩容节点与行距，不把字号越缩越小。画布尺寸、泳道数、节点位置按业务模型调整，保持本风格的间距比例和线型。

## 风格验收

- 检查主轴、边界、文字、线型是否与本快照一致，而不只检查 SVG 能否打开。
- 检查长标识和说明区域不与线相交；分支标题、自循环、节点前后各保留独立空间。
- 如参考图与本快照不同，使用明确的任务内覆盖或新增风格；不能悄悄改写本版本。
