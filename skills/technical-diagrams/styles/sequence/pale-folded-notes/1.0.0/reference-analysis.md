# SQ-04 参考图视觉分析与特征覆盖清单

参考图仅供分析，未获授权保存或展示；本文件只记录可迁移的视觉特征，不复用原图业务内容、接口地址或规则数值。

## 画布与阅读顺序

- 白色长纵向画布，顶部没有总标题、图例、阶段色带或泳道外框；左右与事件之间留有大量白色空间。时间自上而下，参与者横向排列；不同参与者间距并不完全相等，宽度为跨参与者消息和多行标签预留。
- 顶部一排五个等高、近似等宽的参与者头框；不同图不固定为五个。各框水平居中对齐，文本垂直、水平居中；底部没有重复头框，也没有明确结束标记。长图可按实际交付需要重复底部参与者，不将其视为原图已有特征。
- 各参与者正下方的竖直黑色短虚线持续向下延伸，线条与头框中心对齐。注释覆盖生命线时，生命线在视觉上被遮挡，注释不是参与者，也不暗示线条在该处结束。

## 节点、配色与文字

- 参与者使用浅蓝灰填充、黑色较粗描边的小圆角矩形；画布纯白，普通文字深灰近黑。图中不靠不同头框颜色区分职责，也无图标、阴影、渐变或激活条。
- 正文采用清晰的无衬线字体，常规字重；中文与英文、标点和数字混排。消息标签位于横向箭头上方，通常在起止生命线之间居中；长标签分成两行，括号中的补充内容置于第二行。自调用文字放在回路右侧，注释文字居中，必要时换行。
- 参与者框、注释框、消息标签和生命线各有足够间隔；长消息跨过中间生命线不表示与其发生交互。不能因为标签覆盖生命线就推断节点归属，复绘时应通过位置和留白消除可避免的穿字。

## 注释框与组合

- 备注是淡黄色填充、黑色描边的矩形，右上角有向内折起的三角形及折线；主体与折角共同构成一个闭合图形，并非额外的箭头、节点或状态。
- 既有居中压在单条生命线上的短注释，也有覆盖多条生命线的横向长注释；宽高随文本增长。注释位置与附近步骤存在空间关联，但本图没有注释引线，不能凭覆盖或邻近推断明确绑定对象。
- 注释用于说明局部检查、后台处理、重试约束和兜底说明；这些是原图内容类型，不是本风格固定业务规则。新图只显示来源明确的备注，不凭空加入次数、超时或异常策略。

## 线条、箭头与交互

- 跨参与者消息为黑色水平直线，末端为黑色实心三角箭头；箭头指向接收者生命线，左向消息和右向消息均存在。跨越中间生命线不形成连接点。不存在必须额外加折线的普通消息。
- 请求或独立消息在原图中用黑色实线；受理及部分结果返回使用黑色点状虚线。线型记录实际来源，不由线型独自推断同步、异步、处理成功或业务完成。
- 独立结果回调从处理方指向发起方，使用实线；受理响应是相反方向的点线，两者并非同一消息。消息的起点、终点、方向、说明和发生顺序应分别建模。
- 自调用从同一生命线向右伸出，经过上下两个圆角转折后返回该生命线，末端为左向实心三角箭头；原图有多处自调用。回路的上、下端点位于不同高度，标签位于回路右侧，不要画成跨参与者消息或把圆角扩大成曲线环。
- 生命线短虚线、响应点线、消息实线、注释边框和折角是不同图元，不互相替代；原图无消息编号、阶段分区、分支框和图例。技能中的通用交互编号要求与原图无编号是不同层面：新图遵循当前交互规范，复刻时记录差异并按用户要求处理。

## 可复用规则与展示样例验收

展示样例应以独立场景和不同业务模型覆盖以下内容，并将模型与视觉一一核对：

1. 长纵向白底、顶部同排浅蓝灰圆角参与者框、无阴影和短虚线生命线。
2. 横向左右两种实线箭头、左向点线返回和横跨中间生命线的消息；每条线只在目标端有箭头。
3. 一个或多个右侧圆角自调用，入点、出点都准确落在同一生命线上；多行标签在框或线外可读。
4. 淡黄折角短注释和横跨多条生命线的长注释；注释本身不进入消息列表，也不凭空间邻近补关系。
5. 点线受理与独立实线回调分别表示，明确受理不等于最终结果；根据本次任务的来源决定是否标注编号。
6. 节点数量、消息数量、参与者名称、处理过程和注释内容按新任务决定；不可复制参考图原文或业务约束。
7. 原图无图例、底部参与者和激活条；样例需体现其外观，但通用规范允许按任务增加必要元素。普通消息始终水平，独立线条选项主要影响自调用或必要绕行。

以上是观察和可迁移的绘制规则；示例是否实际满足每项，必须在完成 SVG 后逐项检查，并辅以渲染全图和局部。无法完成目视检查时应明确说明。
