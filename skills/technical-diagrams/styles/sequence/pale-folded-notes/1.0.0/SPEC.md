# 浅色折角注释时序 · sequence/pale-folded-notes@1.0.0

绑定公共规范和时序语义 1.0.0，详细取值见本目录 tokens.json，按实际消息数量与标签扩展画布。

白底长画布，顶部对齐浅蓝灰圆角参与者框，黑色短虚线生命线；普通消息为带单向实心箭头的水平线，返回可用点线，独立回调使用实线。文字居中位于线条上方，长文换行；自调用的真实圆角回路落回同一生命线，标签位于回路侧面。淡黄黑边折角注释可覆盖单条或横跨多条生命线，注释不是消息、不凭邻近推断归属；不使用阴影、阶段带或激活条。按来源确定消息语义，不能从线型推断业务结果。原图无消息编号；一般新图按交互规范编号，用户要求复刻时遵循用户要求。

采用其他线条选项时，普通消息保持水平，自调用按线条选项绘制；不得改变消息方向或语义。详情见 [参考图分析](reference-analysis.md)。
