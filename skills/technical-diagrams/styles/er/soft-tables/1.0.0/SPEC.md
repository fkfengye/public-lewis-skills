# 浅色表结构 · er/soft-tables@1.0.0 · ER-01

本快照绑定 `types/er/1.0.0.md` 与 `references/common/1.0.0.md`。独立使用本目录 [tokens.json](tokens.json)，不继承架构图或其他 ER 风格的 token。

参考风格为白底、浅米黄表卡、蓝色文字、灰蓝细边框、浅色行分隔和浅蓝旁注，无阴影、渐变或侧边彩条。参考图中的业务表和字段不是通用契约。

## 表格

表名居中，表头约 76 高；字段行至少 72，高度按换行增加。默认以“字段名 / 键与说明”两列呈现逻辑总览，DDL 详细视图可增加类型、可空性和约束列。PK / UK / FK 仅依据语义来源显示，信息不足不填补默认类型。

基础字段字号 24、关系说明 22；标题与副标题分层，表名 28。字段左对齐，约束说明右对齐或独立列对齐。按最长标识度量列宽，列间保留至少 24 空白；不要把长字段压入约束列。

## 关系与旁注

实体默认横向并列，与用户提供的主实体/从属实体关系配合；复杂模型可改分区或上下布局，不固定三张表。正交线从字段行出发，独立外侧通道承载反向关系；条件引用标签与普通引用分层排布。

本风格沿用参考图的灰蓝实线引用箭头；物理 FK 必须另带明确的 FK 标签，不能仅凭实线判断外键。箭头表示引用字段到目标字段的方向，不表示基数。仅含逻辑引用时，标题下方说明“箭头为逻辑引用，不代表物理外键或基数”；包含物理 FK 的混合模型则写“箭头表示引用方向，关系类别以线旁标签为准”，并在每条线旁区分关系类别，不能把所有线统称为逻辑引用。图例不可省略。

说明卡采用浅蓝白底，放在表格下方或侧方；用文字说明业务约束，关系线不连接说明卡。标题下方说明本图是逻辑/物理模型、箭头含义和未知信息。长图以可读性决定画布与分图，不缩小字段字号迁就屏幕。
