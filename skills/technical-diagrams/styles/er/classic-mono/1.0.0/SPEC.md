# 经典黑白 ER · er/classic-mono@1.0.0 · ER-02

本快照绑定 `types/er/1.0.0.md` 与 `references/common/1.0.0.md`。只读取本目录 [tokens.json](tokens.json)，不加载其他风格快照。

使用白底、黑灰文字、浅灰表头、白色字段行、灰色行分隔及细边框，无阴影、渐变或颜色语义。适合黑白技术文档和打印；逻辑/物理模型都可使用，颜色不能决定关系性质。

表名居中，字段和类型左对齐，键与可空性独立列或并入约束说明列。表头约 76 高，字段行至少 72；基础字段字号 24、关系说明 22、表名 28。长字段与复合键按真实字体度量扩容或换行，不省略字段和约束。

关系使用正交路径、独立字段端口与走线槽。默认虚线箭头为逻辑引用、实线箭头为物理 FK；基数单独标注，箭头本身不表示一对多。鸟爪需要来源和图例，不因使用黑白风格就自动增加外键、基数或级联规则。

条件引用写明条件，反向关系沿外侧专用通道。业务说明放无箭头的独立浅灰/白色旁注卡，不能成为关系端点。主实体顺序按模型调整，不固定三列表。
