# 时序图语义契约 1.0.0

参与者按首次交互和职责从左至右排列；时间从上往下。机构框只是参与者分组，不是大面积阶段底色。请求、响应、异步回调分别建模：原请求的受理不自动等于业务结论，独立回调不能画成同步返回。

实线箭头表示本图声明的调用/消息，虚线箭头通常用于返回/确认；异步语义以消息说明和模型为准，不能仅凭虚线推断。alt/else 是互斥分支，opt 为可选段，loop 给出重复条件。自调用使用参与者侧方小回路。

总体图保留跨系统主线，内部事务和异常细节可指向分解图，避免所有字段塞进主线。已有中间件没有来源证据时不新增；来源示例的角色不能机械替换当前系统职责。

按实际行高安排每条消息：文字块 → 文字与箭头间隙 → 箭头/自调用回路 → 下一条消息间隙。阶段条和 alt/opt/else 标题也占独立行，不复用第一条消息的文字区域。请求/响应码、SLA、事务边界必须来自本任务材料，未知时标待确认。

核验顺序、调用方、返回方向、分支闭合和回调归属；长图重复底部参与者，便于滚动或导出阅读。
