# 数据流图语义契约 1.0.0

数据流图表达外部实体、处理过程、数据存储和它们之间的数据传递。先记录节点 ID、名称、角色、来源及范围，再逐条记录数据名称、两端、方向及依据；不从颜色、形状、位置或业务常识推断未标示的角色、流向、读写、协议、执行顺序或部署关系。未标方向的连线保留为方向未知，不补造箭头、逆向流或响应。

数据流描述数据内容和方向，不自动是控制流、同步调用、返回报文、执行先后或因果关系；交互规范的请求与返回规则仅用于来源明确为消息交互的边。两个不同方向的已知数据流分别独立建模与绘制，分别标注标签和箭头，不以无说明的双向箭头合并。

用户给出 DFD 标准及符号体系时遵循指定记法；未指定时应说明自定义的实体、过程、存储符号，不能声称颜色或形状必然对应某标准。未确认项标明待确认；内容密集时调整节点、端口及标签或拆图，避免线条穿字或穿节点。
