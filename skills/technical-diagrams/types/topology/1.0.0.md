# 拓扑图语义契约 1.0.0

拓扑图以节点、连接和可选分组表达系统、机构、设施或资源的关系。先记录节点身份、所属边界与连接的源、目标、方向、类型、标签及来源，再决定视觉布局；用户提供的连接关系和节点归属必须完整保留。支持有向、无向、多向和不同类型的关系，实际箭头与线型以来源及图例为准。

拓扑可以是链、分支、环、网状或分层结构。不要将空间相邻视为连接，也不要从图标、颜色或画布位置推断职责、协议、部署、上下游、调用、时序或流量。连接是否有方向、请求与响应是否存在、是否有执行顺序均由实际模型决定；交互规范中的单向消息和响应规则只适用于资料明确表示消息交互的连接，不为普通关系凭空添加消息或编号。

同一连线选一个来源支持的方向或无向标记；边的样式和路径几何分别建模。优先将相邻端点对齐并直连；绕行、圆角、曲线和跨线依实际障碍及用户选择绘制。图标仅辅助识别节点，不能替代必要标签或改变节点语义。关系种类不明时明确标注待确认。
