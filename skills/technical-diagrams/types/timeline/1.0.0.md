# 时间线图语义契约 1.0.0

时间线以时间轴和事件表达先后、时间点、近似日期或持续区间。先记录事件 ID、标题、原始日期文字、可确认的日期值或起止区间、时间精度、是否近似、时区（适用时）、来源和说明；无法确认时保留原文并标记未知，不自行补齐年月日。相对时间（例如“今天”）只在来源给出参考日期或制作时点明确适用时转换，并保留原始相对表述。

明确选择轴的方向及尺度：**顺序布局**仅保证先后，不以节点间距表示时长，应清楚说明不按比例；**比例布局**仅在精度、范围和尺度可比较时根据时间间隔定位，并标注尺度或必要刻度。相同时间可并列或分行；近似日期、未定日期和重叠区间须明确标注，不随意改为精确时点。避免因美观重排原始先后或合并有别的事件。

时间轴方向箭头、事件与卡片间的引导线仅表达时间方向或说明归属，不是请求、响应、执行顺序编号或因果关系。事件之间只有在来源明确时才能绘制因果、依赖或交互，并用标签或图例与时间轴区分；交互规范只约束实际消息，不给轴或引导线补造消息和返回。

颜色、形状和位置辅助阅读，不能单独说明事实、重要性或状态；长事件描述可增高、分层、折行或拆图，保留所有来源事实。节点与卡片应明确对应，不将相近时间自动当成同一事件。日期和文字与模型一致，比例轴检查实际位置，顺序轴说明其间距不代表时间跨度。
