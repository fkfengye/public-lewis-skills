# 流程图语义契约 1.0.0

输入模型由步骤、开始/结束、判断、条件边和可选泳道组成。判断节点的每个出口有可区分的条件，回边显示重复的边界；不要只写“是/否”却看不出问题是什么。

默认上到下，用户指定横向时改变主轴。主路径居中，失败/退出路径放侧边；归并用清楚的汇合点，交叉不等于连接。独立角色使用泳道，泳道是职责而非运行状态。

动作通常圆角矩形、判断菱形、起止使用端点/胶囊；具体填色和大小由风格规定。不得为了图形对称把一个实际步骤拆成不存在的服务，也不省掉失败结束边。

复杂分支先核对每个输入条件对应到达的终点，循环要能看出何时退出。标签与判断框外缘保留可读间距，优先调整分支长度而非让回边穿过主步骤。
