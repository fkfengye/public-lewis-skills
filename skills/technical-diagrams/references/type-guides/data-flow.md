# 数据流图使用指南

语义契约以 `resolve` 返回的 `type_spec_path` 为准（[数据流图 1.0.0](../../types/data-flow/1.0.0.md)）。按来源建模过程、外部实体、存储和数据标签；方向未知的连接保留未知。

## 使用要点

- 过程、外部实体、数据存储用不同形状区分；数据标签跟随连接，不把标签当作节点。
- 已知数据方向才画箭头；方向未知的连接保留为无向，不凭布局补方向。
